```
Build support for the target device not found
```

**原因**：CY8C4149AZI-S593 的设备支持文件不在当前 BSP 中

**可用的类似设备**：
- cy8c4149aza_s598.h（类似型号）

## 🔧 解决方案

### 方案 1：使用类似设备（快速）
修改 TARGET 为类似的已支持设备：
```makefile
TARGET=CY8C4149AZA-S598
```

**风险**：引脚定义可能不同

### 方案 2：手动添加设备支持（标准）
1. 复制 `cy8c4149aza_s598.h` 为 `cy8c4149azi_s593.h`
2. 修改引脚定义
3. 添加到 BSP

**时间**：1-2 小时

### 方案 3：使用现有固件（推荐）
**保持使用原始固件**，因为：
- ✅ 已完全理解（v54 逆向结果）
